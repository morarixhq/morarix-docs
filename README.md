# Morarix Docs

Long-form documentation, concepts, and posts for
[Morarix](https://github.com/morarixhq/morarix) — the CLI that provisions
real, prod-like dependencies (Postgres, Redis, Kafka, LocalStack, ...) from
a hand-authored dependency graph, for local dev and CI alike.

## Start here

- [Why Morarix](concepts/why-morarix.md) — the problem this solves and why
  it's a CLI + graph instead of a library or a shared staging environment.
- [Usage guide](docs/usage-guide.md) — onboarding a service, the testing
  philosophy (the three layers), and the exact commands for local dev and
  CI.
